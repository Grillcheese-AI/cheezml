CheezML

One record vocabulary for CubbyLLM, MoWM and CubeLang: an answer and its certificate, a refusal and its reason, a routing choice, a world split, a rejected helper, a document field reviewed by a person. Each record is written by the host from what actually ran, so it can only say what happened.

In plain words: every answer comes with a receipt you can check, in the same format as every routing choice and reviewed document behind it. Nothing in a record is a claim the system makes about itself: no truth score, no status declared by hand, no prose rationale.
